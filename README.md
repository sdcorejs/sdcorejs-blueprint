# SDCoreJS Blueprint

Bộ quy ước, kiến trúc và mẫu triển khai cho các project trong hệ sinh thái SDCoreJS.

- [Angular](angular/README.md): module/feature tự chứa, public configuration, routing, services, assets và tổ chức test.
- NestJS và React sẽ có nhóm Blueprint riêng khi được xây dựng.

Markdown là tài liệu tham khảo cho AI và developer. Phần HTML diễn giải trực quan sẽ được bổ sung sau, dựa trên cùng các quy tắc đã thống nhất.

## Phạm vi hiện tại

Đã có cấu trúc project Angular và các mẫu code nền tảng. Giao diện nghiệp vụ dùng Core UI thuộc [UI patterns](angular/ui-patterns.md), được phát triển riêng.

Các ví dụ MDM/Product là tên minh họa, không phải module bắt buộc hoặc API backend đã tồn tại.
